# 项目版本与验收用语

本项目用以下词语区分功能、画面范围和验证状态。

## 用语

**直显版**：将摄像头画面输出到显示器的版本，支持颜色调整，不包含完整边缘检测与帧操作系统。

**完整边缘版**：包含Sobel、完整Canny和冻结、单步、录放、参考对比等功能的版本。功能存在与每项效果已验收分开表述。

**画质优化版**：在完整边缘系统基础上改进颜色恢复、滤波或边缘处理的版本；不意味着全部画质问题已经解决。

**全视野**：使用传感器完整2560×1440视野；显示缩放到720p仍可保留全视野。

**裁切视野**：只使用传感器中央部分区域。当前60帧版本属于此类。

**采集帧率**：摄像头每秒提供的图像帧数；不能用显示器刷新率代替。

**人工验收**：用户针对指定版本、设置和观察效果作出的确认，不自动覆盖该版本所有功能。

**离线通过**：指定仿真或构建检查已通过，不表示已在板上获得相同画质或吞吐表现。

**默认关闭**：功能仍在工程内，加载时不启用；与删除功能不同。

**串行演示**：按固定先后顺序逐项展示赛题功能的过程，每一步对应明确的展示目标。演示者可以向前推进或返回前一步。

**演示步骤**：串行演示中供观众观察一项效果或验证一组相关要求的环节。它按展示目标组织，不等同于原来的参数菜单项。

**车牌定位**：确定一幅图像中车牌所在的区域；定位成功不代表已经读出号码。

**车牌号码识别**：从车牌图像中读出字符并组成完整号码。与仅显示灰度图或车牌轮廓分开表述。

**同帧处理对比**：对照同一幅源图像的不同处理结果，例如灰度图与边缘图。

**历史画面对比**：对照先前保存的画面与其他保存画面或当前画面；画面可以来自不同车辆或同一车辆的不同时刻。
