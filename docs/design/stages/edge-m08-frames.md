# M08：冻结、录制、回放和参考帧

状态：M08实现、仿真、构建和板上自动检查通过，已建立独立恢复备份。2026-10-11用户确认“按键和画面都正常，M08验收通过，继续M09。”，实物人工验收通过。

## DDR 前置检查

2026-10-11，从已验收M07备份建立独立工程
`camera_trials/m08_ddr_probe/Ti60f225_sc431hai2hdmi_v7`，复用原DDR控制器和PHY。
配置为16位数据、14位行、10位列、8个bank，对应256MiB。

启动检查先写完所有探测地址再统一读回，使用两组互补数据。地址覆盖字节地址位
4～27、每个4MiB区域的首／末128位字、零地址，最高地址`0x0FFFFFF0`。
不同地址使用不同数据；重复地址使用相同数据。306次板上读回全部匹配，
`memory_done=1 / memory_failed=0 / memory_checks=306`。
这是地址可达和所探测地址无别名的证据，不是逐字扫描256MiB的内存压力测试。

独立仿真覆盖AXI停顿、正常256MiB地址空间和人为截断为128MiB的别名；后者被检出。
验证位流标识`0x60101080`，四阶段构建通过，最小建立／保持余量0.366／0.026ns。
日志为`logs/edge-m08-ddr-probe-{build,load,status}.log`。检查后恢复M07主线位流。

## 帧引用管理

`frame_store_control.v`将捕获、算法任务、显示预取、实际显示、冻结、32帧片段和
独立参考帧分别持有的引用集中在DDR时钟域。命令改变任务版本，旧事务正常结束，
版本不匹配的结果不得发布。显示读取完成后仍保留预取结果，直到HDMI切换确认。

原帧池使用41个4MiB槽，结果三缓冲占12MiB，合计176MiB。录制通过32项槽位表
保留原帧，重新录制释放旧片段引用；参考帧引用独立保留，因此不需要整帧复制。
地址已经接入主线。与总体设计的184MiB全功能预算分开记录，
M09工作区尚未分配。

控制层定向仿真已覆盖冻结不变、参数版本更新而原图编号不变、单步重新冻结、
32帧按序录制及暂停单步回绕、重新录制保留独立参考、输入源切换的迟到结果隔离。
这些检查不替代完整像素、CDC、DDR、构建和板上验收。

## 数据路径与容量

相机仍为全幅2560×1440 RAW10、约30fps，2×2 Bayer合成完整1280×720 RGBY。
M08先将完整RGBY帧写入DDR，再由统一读口送入原有中值／Sobel模块，处理结果写入
三个结果槽，HDMI以60Hz读取。实时路径因此增加一帧存储延迟；冻结、实时单步和片段
回放均复用同一算法路径。只有完整帧最后一个AXI写响应成功后才发布。

每帧921600像素×4B=3686400B；每槽4MiB。原帧槽0～40占164MiB，结果槽41～43
占12MiB，总计176MiB，剩余80MiB。32帧录满即暂停到首帧，继续录制必须明确执行
RECORD。独立参考引用不会因重录而释放。参考视图左侧为参考原灰度、右侧为当前原灰度，
两侧同为完整640×360视野；参考比较不替换算法源，也不改变Sobel输入。

## 操作

KEY0保持复位。KEY1为P14/GPIOR22，KEY2减、KEY3加。KEY1短按依次选择VIEW、T、
MEDIAN、FRAME；FRAME中短按执行当前动作并返回VIEW。KEY1长按800ms在实时／录制时
冻结实际显示帧，在冻结／回放时恢复实时；长按释放不追加一次短按。

VIEW包含COLOR、GRAY、EDGE、COMPARE、DENOISE、OVERLAY、REFERENCE；参考不存在时
不会进入REFERENCE。T为0～2040、步长16，支持按住连发；其他枚举每次按下只变化一次。
FRAME动作依次为CANCEL、STEP、RECORD、PLAY、PAUSE、NEXT、SET REF、LIVE、CLEAR REF。
菜单位于图像底部，上方显示状态及F原帧号、V参数版本、R参考帧号，三个编号为十六进制。

CLI入口为`camera-control.cmd --edge`，增加`--frame live|freeze|step|record|play|pause|next|reference|clear-reference`
及`--view reference`。`step`在片段回放／暂停时执行下一帧，其余状态采集一张新完整帧并冻结。
构建标识为`0x60101008`，必须使用本阶段profile和脚本。

## 两分钟实物验收

初始状态为LIVE／COMPARE、T32、M1，菜单焦点VIEW。KEY1短按选项，KEY2减、KEY3加；
FRAME项短按KEY1执行。长按KEY1约0.8秒在冻结与实时之间切换。

1. 长按KEY1，确认FRZN；移动物体10秒，图像及F帧号不变。
2. 短按KEY1到T，按KEY3提高阈值再按KEY2还原，边缘变化而F不变，V更新。
3. 再短按两次KEY1到FRAME，选择STEP并执行：只换一帧，随后继续冻结。长按KEY1恢复LIVE。
4. 到FRAME选择RECORD并执行，同时移动手或物体；约1秒录满后自动PLAY PAUSE。
5. 到FRAME选择PLAY并执行，确认刚才动作循环；长按KEY1恢复LIVE。
6. VIEW中切到REFERENCE，确认REF标识、左参考静止、右当前图随物体变化，F与R各自显示。

F／V／R以及录制计数C以十六进制显示；录满32帧时C=20。
以上由用户观察确认；自动验证不替代实屏与实体按键反馈。
