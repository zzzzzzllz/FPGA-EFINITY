# 唯一Q30区间CTC：执行前冻结合同

2026-10-18。主控授权仅对冻结307dev及85校准logits做一次离线验证。模型、logit尺度、严格门限、base颜色/边界门控及候选排序规则不变。无图像读取、训练、网络推理、112heldout或RTL。Q30固定，不按84结果改位宽；128bit只作为带证明的离线参考，不是第二个部署候选。

## 依据与证明方法

已重读下载的LiteRT softmax.h的减最大值、exp/分母/倒数路径，以及PyTorch LossCTC.cu的三路转移、重复标签禁止跳两状态和末两状态求和。沿用此数学定义，不移植其8/16bit概率量化。文件在 `integer-deployment-research/`、`fit-gate/research/`，SHA入协议。

Python官方[Fraction文档](https://docs.python.org/3/library/fractions.html)说明浮点可转换为其精确二进制有理数；s和tau均通过 `as_integer_ratio()` 转换，不把十进制显示串当作精确值。

对每个d=0..1020，设x=d*s，选最小非负k使y=x/2^k≤1/8。用精确Fraction计算 `S_n=sum(j=0..n,(-y)^j/j!)`。因项绝对值单调递减，交错级数定理给出 `S_31≤exp(-y)≤S_30`；代码检查0≤y≤1/8及逐项递减。先将这两个有理数向外取到Q128，再重复k次区间平方：下界floor(L²/2^128)，上界ceil(U²/2^128)。正区间平方单调，因此最终区间包含真实exp(-d*s)。d=0单独精确为1。记录每个d、k、精确y及最终整数界，全部1021项核对。Decimal 100位exp可作独立交叉检查，但不参与证明或Q30界生成。

tau按原binary64精确转换后直接取有理数七次方，保存分子/分母及Q30向外界；这一步无需近似exp/log，也不使用普通double生成阈值界。

## LUT、softmax和DP

1. 输入int16 logits[68,18]，范围[-764,256]。每列减最大值后取非负差d，保留全部68类、blank67；相等argmax取较小类ID。先合并相邻重复，再去blank。
2. Q30 exp表仅存d=0..70。d=0上下界均2^30；对d=1..70，Q128证明界必须落在同一Q30网格单元，由该单元floor及floor+1作为界。若不能证明，则停止报告，不猜测。d≥71使用[0,1]/2^30；全部1021个差值必须由Q128证明界验证包含关系。
3. 对68项exp界求和。发射概率下界为floor(exp_lo×2^30/sum_hi)，上界为ceil(exp_hi×2^30/sum_lo)；上界可按真实概率≤1截紧。最大项精确1确保sum_lo>0。分母最多37bit，分子最多61bit。
4. 合法七字使用15状态。初始化时间之前blank状态为[1,1]，其他状态0；每步对自身、前一状态，以及允许时的前二状态求和，乘发射概率并分别向下/向上舍入。跳两状态仅在当前非blank且与前二状态字符不同；所有状态必须读上一时间步，不能原地覆盖。上界按真实状态概率≤1截紧。最后合并末两状态，空目标仅blank状态。三项上界和最多32bit，乘积最多62bit。
5. 每ROI均保存目标、概率下/上界和状态。非法七字直接按原grammar拒绝，不能因区间分数高而放行；为满足逐ROI审计，离线程序也计算其原greedy目标的概率区间，状态数为2L+1。这些非15状态诊断不作为硬件接口扩展。
6. 同一递推在Q128 exp界及Q128状态下形成参考概率区间，并验证它包含于Q30区间。另保存原浮点CTC概率是否落在Q30界内；浮点乘尺度和exp的舍入与实数数学并非逐位相同，不能拿数学单调关系代替这一检查。

## 接受与多候选排序

令T为tau精确有理数的七次方。若Q30下界≥T则确定接受，若上界<T则确定拒绝，否则标为undecided。接受含等号。硬件可使用离线ceil(T×2^30)和floor(T×2^30)比较；测试另外覆盖精确网格阈值的等号情况。

候选先按原合法性及指定base gate筛选，再比较概率区间。只有候选下界严格大于其他候选上界时，才能确定分数更高。两候选若概率均为同一精确点，或原整数logits与目标逐元素相同（可证明同概率且浮点流程相同），按较小ROI索引处理精确同分。其他重叠不等于同分，保留可能获胜的ROI集合并标为排序未决；即使两者都过阈值，也不得静默挑一个。

每张保存OCR单独及base组合的选择/接受状态，与冻结浮点CTC结果逐项比较。任何阈值或排序未决单列，不记作默认拒绝；不靠结构门控、位宽调节或新阈值消除差异。精确logits相等证明是离线比较依据，其硬件比较/存储接口若需要，必须另验证，不能仅以hash相等代替证明。
