# 静态常数旁路与固定六步 RNE：独立实现结果

2026-10-18。候选 `requant_static/` 已完成独立RTL、map及有界映射仿真。相对冻结Q31增加311 LUT、1 FF，减少7 ADD，RAM和DSP不变。全int8域证明覆盖658,256个静态输出；按已验证的事务周期，LPR已知核心减少82,566,768拍。冻结Q31、MAC、权重bank、部分和、模型及显示合同均未修改。

## 证据与方案选择

实际读取了以下下载源码，文件位于 `tmp/blue-plate-review/service-research/`，URL与SHA256见该目录 `research-record.json`，并收录在本候选验证清单：

- [hls4ml nnet_dense_latency.h](https://github.com/fastmachinelearning/hls4ml/blob/main/hls4ml/templates/vivado/nnet_utils/nnet_dense_latency.h)：固定权重乘加及偏置累加。源码本身没有本候选的通道常数证明，不能把本实现说成直接移植。
- [FINN MoveMaxPoolPastMultiThreshold](https://github.com/Xilinx/finn/blob/main/src/finn/transformation/streamline/reorder.py)：读取986–1045行，确认单调变换和无分叉的适用条件。其交换方向及分叉限制不适合直接套入tap2，本次保留原图。

选定完整输入域上的通道常数证明，以及固定六步移位。它不需要稀疏执行器或新增乘法器，可保留原始稠密MAC、地址和部分和接口。实现前的契约、周期目标和资源计量方式保存在候选README中。

## 静态证明与参数接口

对每个冻结通道，令 `P=Σmax(w,0)`、`N=Σmin(w,0)`，独立输入项均取signed int8全域，则：

```
lo = bias - 128*P + 127*N
hi = bias + 127*P - 128*N
```

检查上下界仍在int32内，所有M为正Q31，shift在1..62。ReLU、正比例缩放、RNE、加zero及饱和均单调；只有两端得到同一A8时才标记常数。该证明不使用实测激活范围，包含padding可能值，忽略输入相关性只会使区间更宽。

独立核对主控证明后，1,640条通道记录中873条恒定，对应658,256个输出；动态输出718,320个。`requant-static-proof-and-schedule.json`保留每条记录的原bias/M/shift/zero、上下界及常数值。tap2两路独立证明，当前不存在“主分支常数、次分支动态”组合。脚本对此作断言。

`q_const/q_const_value`由已证明的描述符提供，常数请求直接输出原A8值，保持MAC、RAM及原始标量不变。派生参数可复用72bit行：bias32不变；原M32最高位作为标志，常数时低8位存原A8；动态时原M/shift不变。没有修改冻结NPZ，也不增加平行参数RAM。完整参数加载器与调度器尚未实现，本次验证的是该端口契约。

常数通道仍执行原稠密MAC并参加组save，只省去该标量的restore和Q31；必须将常数写回原稠密输出地址。未来若出现主常数、次动态的模型，次分支必须先restore并以非reuse装入原值。当前证明不能授权未来模型复用旧描述符。

## 六步精确舍入与周期

两个乘法批次及10项64bit重建沿用冻结实现。SHIFT阶段按shift的六个bit依次选择移1/2/4/8/16/32位；每次移位保留guard，sticky合并所有更低丢弃位。未移位时保持商及guard/sticky，第六步执行一次ties-to-even加1。负数使用算术右移的floor商，随后按原规则加zero并饱和。

动态请求接受后固定25个有效边沿产生valid；接受、消费各计1拍，总27拍。常数在接受边沿产生valid，下一有效边沿可消费，总2拍。CE或ready停顿另计。小shift可能比旧实现多用几拍，逐通道总账已经包含该代价。

|---|---:|

## 验证与独立综合

- 六步RNE用有理数精确舍入独立比较6,882组64bit值，覆盖shift1..62和有符号端点。
- RTL：2,387例，其中1,787例常数；25,951测试拍、1,200次注入停顿。873个常数通道的上下界均作为旁路输出用例；常数正确性来自上述区间证明，旁路测试验证输出及握手，不将直接送入期望值当作额外数值证明。
- 映射仿真：271例，其中91例常数；6,147测试拍、360次注入停顿。两种仿真均在动态请求第18个有效边沿检查完整64bit乘积，并检查25拍延迟。
- 100个既有真实标量记录由64个当前主/次分支记录及36个历史数值回归记录组成；后者只作算术回归，不用于本模型的常数范围。当前常数旁路按冻结通道证明启用。
- 覆盖正负ties、饱和、所有shift、输入接受后变化、CE/背压、动态busy冲突、非法参数/reuse、原RAM槽保留、未排空MAC拒绝、六个移位边界复位，以及“ReLU动态→常数→无ReLU复用”原始负值保留。

映射仿真沿用已审查的本地LUT启动修正：只把仿真副本的输入敏感列表改为 `always_comb`，使全零初始输入也求值；未改RTL、网表或厂商安装文件。本候选152种LUTMASK通过39,064次启动/四态真值表比较。映射PASS以该明确的仿真模型修正为条件。
