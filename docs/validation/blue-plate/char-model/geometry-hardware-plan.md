# geometry signed11：受控硬件验证计划

主控授权范围：原独占 char_model 目录内修改单一 `char_linear` 的权重位宽参数，默认仍10位；ROM路径已有参数，保持默认文件与门限不变。实验目录只验证软件优选 geometry 的可实现性，不替换正式候选，不修改共享top/DDR/char_preprocess。

1. 读取NPZ `b21a547399f17ecb50264d489eec4e4563c2269babab7149dc5447f7a12f5391`，逐值范围检查后导出11位二进制ROM及32位bias；反向解码20800权重/65偏置必须精确相同。
2. 现有内核新增WEIGHT_BITS（默认10），权重寄存器/ROM和有符号乘积宽度随参数变化；输出/累加仍signed32，特征和状态机不变。门限、路径使用已有参数，不建立第二套分类逻辑。
3. 原测试台最小参数化并扩大向量存储容量；原默认159向量保持同一结果与41796拍。实验使用全部259个冻结真实ROI、极值/随机/同分及负权重越过10位边界的输入；另用明确标记的合成11位极值ROM检查-1024/1023等边界。
4. geometry实验独立map，报告实际RAM/DSP、ROM归属及周期；保留默认candidate全部文件SHA。输出证据、复现命令和真实识别边界。

依据：已实际阅读 Efinity 同步ROM推断说明和当前经验证的 `char_linear.v`、159向量测试台、原map工程。采用其既有同步读模板及有符号乘法，仅把10位改为参数；不改变归一化、320特征、65类、位置允许集合或较小ID同分优先。

状态：完成。默认159向量与geometry320向量通过，两档边界测试各36向量通过，11位map通过36RAM/1DSP；主控独立复算默认、geometry、11位边界及ROM全部通过。映射后9向量、715次分数比较、41796拍与协议断言全部通过，最终证据见 [geometry11-hardware.md](geometry11-hardware.md) 和 [冻结清单](geometry11-hardware.json)。

验证中修复了驱动循环变量遮蔽导致的错误32位参数（内核明确拒绝，未放宽检查）；门级300秒时限不足，最终增加实时进度日志并以1800秒时限完成，实际747.062秒。模型、综合网表、核心测试断言未为绕过失败而修改。
