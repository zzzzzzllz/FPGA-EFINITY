## 位精确规则

- 输入为M02的Y8；可选严格3×3中值，逐级使用复制边界。
- 高斯核为`[1,2,1;2,4,2;1,2,1]`，完整加权和后`(sum+8)>>4`，仅此处舍入。
- Sobel的Gx向右为正，Gy向下为正；幅值为11位`abs(Gx)+abs(Gy)`。
- 方向使用`ay*256 <= ax*106`判水平；否则`ay*106 >= ax*256`判垂直；其余按Gx/Gy同号取左上／右下，异号取右上／左下。轴向边界等号归轴向。
- NMS固定先比较左、上、左上或右上，再比较其对侧：`G>前邻 && G>=后邻 && G!=0`。连续等幅平台只保留沿上述方向的起始像素；不作有限轮次形态学补线。最终外圈一像素清零。
- Canny高阈值1～2040；低阈值分别为`Th>>2`、`Th>>1`、`(3*Th)>>2`。`G>Th`为强，`Tl<G<=Th`为弱，其他为非边。
- 所有强边作为种子；八邻域弱边先标记接受再入队；队列空才结束。每像素最多入队一次，容量W×H。
- 坐标工作队列按后进先出顺序遍历，优先处理刚接受的邻居，减少状态图跨区域访问。种子集合和接受条件不变；与独立的广度优先／连通分量参考比较最终集合，不要求相同访问次序或相同队列高水位。

## 接口方案

复用M08串行job、原帧引用和DDR控制器。局部分类暂存未发布的结果槽，RGB24保留；DMA在写入同一结果突发时打包2位分类，随后写入该结果槽独有的状态平面。最后一个状态写响应完成后才启动滞后连接。邻域缓存保存2位状态，按4条、每条64个AXI拍组织；弱点先标记为接受，再放入后进先出的坐标工作队列。

工作队列清空且所有脏缓存写响应成功后才发布结果。显示DMA读取已发布槽的状态位，与原RGB、帧号和实际配置合成输出，省去整帧最终写回。参考对比只用灰度，跳过状态位预读。RGB与状态平面由同一个结果槽生命周期保护；新job不能修改正在显示的槽。LIVE/RECORD允许在上一结果等待显示时使用空闲槽启动下一个job，仍只有一个算法job运行。所有DDR写入均为完整128位，不依赖字节掩码。Sobel复用同一梯度入口。

结果槽0、1、2的状态平面分别位于`0x0b400000`、`0x0b440000`、`0x0b480000`，每槽预留256KiB，720p实际使用230400字节。坐标工作队列位于`0x0b000000`，容量921600×4B。原帧与结果槽176MiB、队列预留4MiB、三个状态平面预留1MiB，共181MiB。
