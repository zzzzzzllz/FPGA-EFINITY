# 新普通蓝牌部分集：右边框误切诊断

2026-10-18。固定预选 500 个新车牌身份，已下载并校验 196 张；只运行开发 131 张、校准 28 张。37 张已下载留出图未推理、未预览。不是 500 张验收，也不是场景隔离验收。

## 已确认根因与修改

开发集自动误接受 1 张是 `皖A43Y26 → 皖A43X26`，二值 Y 清晰，属于字符判别问题。真值四角区域的 10 张误接受全部错在末位：9 张的末位字符框混入独立右边框，剩余 `皖AX815V → 皖AX815W` 是 V/W 混淆。已人工查看原灰度和实际二值字符。

原清理条件只去除 `x>210,w<5,h>23` 的边缘连通块，漏掉宽 5–10 像素或较短的边框。保持 224×64 归一化板面、连通块和投影流程，将独立右边缘块条件改为 `x>=210,w<=10`。随后从原灰度字符框重新二值化。没有裁掉整列，也没有调整模型或门限。

成熟参考仍为已读取的 [EasyPR 字符切分源码](https://github.com/liuruoze/EasyPR/blob/a0a9f3c3f612e7c8d9046bd9c5770249cfb86850/src/core/chars_segment.cpp) 与 [核心处理源码](https://github.com/liuruoze/EasyPR/blob/a0a9f3c3f612e7c8d9046bd9c5770249cfb86850/src/core/core_func.cpp)：几何清理后提取字符，再从原灰度重做阈值；本次具体边框条件来自冻结错误图的连通块实测，非声称照抄上游。已下载源码在 `tmp/plate-research-20261018/`。
