# M06：3×3 中值滤波

状态：仿真、构建、SRAM下载与板上自动验证通过；用户回复“可以了下一步”，M06人工验收通过并放行。

## 操作

默认仍是灰度／Sobel 对比，阈值32，中值开启。KEY2/KEY3继续调阈值；KEY0复位，KEY1未占用。本阶段通过现有JTAG入口切换去噪与旁路。

```bat
camera-control.cmd --edge --view denoise --median on --samples 1
camera-control.cmd --edge --median off --samples 1
camera-control.cmd --edge --median on --samples 1
camera-control.cmd --edge --view compare --samples 1
```

去噪视图左侧原灰度、右侧中值级输出，都是640×360完整视野，位置(0,180)/(640,180)。旁路关闭滤波时两侧应一致。`T=0032`为实际画面阈值；`M=1/0`为滤波开启／旁路，`D=1/0`为去噪对比／其他视图。标签来自已进入HDMI的帧元数据。`--view color|gray|edge|compare`四种已有视图继续可用。

`median_active/denoise_active`是采集帧参数，`median_shown/denoise_shown`是实际HDMI帧参数；`median_epoch`记录滤波或去噪视图提交次数。只读状态不会重置控制。加载入口保持白平衡389/256/427、Gamma0、Bayer0。

## 实现

`median_pair.v`复用双像素窗口时序，每个像素以九层奇偶比较交换网络排序九个8位灰度，取第五个值。四边复制最近像素，输出1280×720；旁路使用相同窗口和流水线延迟。参数在输入SOF锁定，原RGB、帧号、参数版本、SOF/EOL/EOF一起通过流水线；后级Sobel使用当前帧的滤波结果与阈值，最终最外圈一像素仍强制非边缘。

采集不可反压，顶层记录中值入口无法接受有效数据的次数，沿用`sobel_overrun_cycles`诊断字段。仿真另外验证可停顿接口的稳定性。算法仍运行于现有50MHz双像素域，不改跨域和DDR架构。

常规视图的DDR记录保持原RGB24、边缘位及帧标记。去噪视图的DDR显示载荷改为R=原灰度、G=滤波或旁路灰度、B=0，减少额外帧存储；原RGB完整保留到Sobel输出，原灰度按同一定点公式从该RGB恢复。显示器根据该DDR帧的标志解码，不根据尚未生效的视图请求解码。切回彩色后显示新采集的RGB帧；本阶段不提供冻结帧重处理。

DDR首字第1号像素携带阈值低7位，第2号像素高7位为`{0,D,M,T[10:7]}`；第0/3号像素及后续像素保留帧标记。`compare_display.v`完成所有视图的RGB合成及2×2缩小，再进入实际HDMI FIFO。灰度和中值各自四像素四舍五入平均，边缘四像素OR。`threshold_osd.v`从输出帧前两像素读取参数，多位状态用原有握手快照读回。

## 两分钟人工验收

1. 当前去噪视图：确认底部M=1、D=1；左为原灰度、右为中值输出。移动带文字或轮廓的物体，两侧应同步、位置和比例一致。
2. 对准较暗的平坦区域或细纹理，观察右侧孤立亮暗点是否减少，主轮廓是否可辨；细节变柔和属中值处理结果，效果按实际画面反馈。
3. 运行旁路命令，确认M=0后左右一致；重新开启，确认M=1后恢复处理效果，切换不应出现错位或半帧状态。
4. 切回compare，确认灰度／Sobel对比正常，KEY2/KEY3仍能调节阈值。记录噪点减少程度和轮廓变化。
