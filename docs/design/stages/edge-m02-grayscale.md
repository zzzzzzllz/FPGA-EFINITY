# M02：全视野灰度

状态：灰度逻辑、仿真、构建和自动板上检查通过；用户已于 2026-10-10 确认人工验收通过。

## 本阶段实现

- 输入继续使用稳定的 SC431HAI 全幅 2560×1440 RAW10 约 30fps，经 2×2 Bayer 与白平衡输出 1280×720。
- 灰度按 `Y=(77R+150G+29B+128)>>8` 四舍五入；DDR 每个 32 位像素为 `{Y,R,G,B}`。不裁剪，不覆盖原始颜色，也不增加帧缓存带宽。
- 灰度流水级带 `valid/ready/sof/eol/eof/frame_id/config_epoch`，停顿时保持整个输出。当前直接接现有 50MHz 双像素通路，实际下游恒 ready；后续窗口算法再建立总体设计中的 100MHz 单像素入口。
- 摄像头增益和 Bayer 相位在帧消隐期锁定；记录参数版本及最后完成灰度帧的 ID／版本。这里只建立算法侧元数据，完整 DDR 帧描述符、引用管理及显示帧 ID 尚未实现。
- 灰度默认开启，Gamma 默认关闭，白平衡初值为 397/256/471。彩色／灰度与 Gamma 的显示切换在 HDMI 垂直消隐生效。
- 新增参数读回、灰度处理帧计数、MIPI 标志有效周期计数、HDMI 欠载周期计数。欠载计数用寄存 Gray 编码和两级同步跨时钟；这些计数表示异常信号持续的周期数，不是异常包数。
