## 2. 唯一首轮候选与可执行接口

实现：`tools/blue_plate/char_segment/lprnet_cost.py` 中 `Candidate(8, native=True)`。输入 N×1×48×160，输出未归一化 logits N×66×35。类别严格沿用 `char_model/candidate/interface.json` 的65类顺序，末尾增加 blank=65，清单和接口哈希进入JSON。

| 层/操作 | 输出 C×H×W | 说明 |
|---|---|---|
| 3×3 conv + BN + ReLU | 8×46×158 | 无padding |
| 3×3空间max，步长2×1 | 8×22×156 | 通道不变 |
| small block 8→16 + BN + ReLU | 16×22×156 | block见下 |
| 通道隔2抽取，3×3空间max，步长2×2 | 8×10×77 | 非通道最大池化 |
| small block 8→32 + BN + ReLU | 32×10×77 | |
| small block 32→32 + BN + ReLU | 32×10×77 | |
| 通道隔4抽取，3×3空间max，步长2×2 | 8×4×38 | |
| 1×4 conv + BN + ReLU | 32×4×35 | 训练前有dropout0.5 |
| 1×1 conv + BN + ReLU | 66×4×35 | 训练前有dropout0.5 |
| 四分支池化、逐样本能量缩放、拼接 | 122×4×35 | 池化参数见下 |
| 1×1 conv，沿H取均值 | 66×35 | 不增加末端ReLU |

small block：1×1→3×1→1×3→1×1，中间通道为输出通道/4，前三层后ReLU，空间卷积padding保持尺寸。沿用公开复现的block外BN，未虚称论文中每层卷积后BN均已复现。推理关闭dropout并折叠可折叠的BN。

四分支为stem、第一block、第三block、最后head。前三者平均池化 `(kernel,stride)` 分别是 `((11,22),(11,4))`、`((5,20),(5,4))`、`((4,9),(2,2))`，head直通，均得到H4、T35。源代码的4D MaxPool3d在本用法中等价于 `x[:,::channel_stride]` 后2D空间max；batch1/2、通道步长1/2/4已逐元素一致。不是通道组内取最大值。

脚本还核算 C8-24×94（T18）与 C16-24×94，作为分辨率和容量成本参照。本轮不启动比较矩阵。首轮先由主控用固定教师区分同几何下 RGB48×160、复制灰度48×160、降采样后再适配教师输入的损失；教师接口仍是48×160，不能直接喂24×94。该诊断只用于理解输入信息损失，不能证明小网络容量足够。

### 输入适配

训练和硬件共同从实际自动几何输出的224×64灰度ROI开始。若从RGB生成灰度，遵循当前整数 `((77R+150G+29B)>>8)`；已有灰度不可再次转换。第一版统一拉伸至160×48，与教师自己的等比缩放/补边分别记录。

固定整数双线性：源坐标 `u=(2x+1)*224/(2W)-0.5`、`v=(2y+1)*64/(2H)-0.5`；先夹到源图范围，再取floor邻点。小数部分×256，按非负half-up取整；若为256则进位到下一整数坐标并设小数为0，邻点夹边。两轴Q8权重乘积为Q16，像素输出 `(acc+32768)>>16`。最大加权和255×65536，含舍入仍在24位无符号范围。坐标和分数可预先生成ROM。训练必须用同一整数参考生成输入，不能悄悄换OpenCV/Pillow插值。归一化定义 `(gray-127.5)/128`；与教师 `/127.5` 分开。后续已在experiment.py实现，以独立有理数标量参考核对随机图、常量、边界及上/下采样后用于训练。

## 3. 动态上下文及定点代价

学生每个分支 `f` 用 `E=mean(f², axes=C,H,T)`，`f/max(E,1e-6)`；每个样本独立。公开复现的全tensor均值会跨batch，且没有epsilon；不能直接把它作为新训练模型规范。脚本检查学生eval分批结果一致到1e-5以内、全零输入有限。

E是输入相关量，不能折叠为BN。固定BN缩放可作为以后从头训练的简化备选，但会改变模型，须另做效果实验；本首轮只保留动态能量版本。

由于最后1×1投影和高度均值都是线性的，可按分支执行：

`logits = bias + Σ_j W_j · mean_H(f_j) / max(E_j,1e-6)`

各分支算完能量和高度和后即可投影并累加，bias只加一次，无需物化拼接的122×4×35张量。已用原公开预训练网络、3个随机输入、float64验证重排，最大绝对误差3.5527e-14；这验证线性关系，不是INT8等价证明。

拟定W8、激活A8、卷积INT32累加；权重按输出通道量化，激活按tensor/分支尺度。ReLU分支若用uint8，最大9,240项平方和为600,831,000，32位无符号足够。每ROI四次动态倒数/增益计算仍需实现，epsilon要换算到对应量化尺度；除法近似、64位乘积中间值、舍入和饱和必须纳入QAT与golden reference，不能靠整数除法截成零。所有scale/offset/epsilon须入导出清单。

存储假设：最大分支高度和66×35×16bit=4,620B，加最终66×35×32bit累加=9,240B，合13,860B，约14个RAM10。该数不包含主干卷积工作区、平均池化行缓存、计数/倒数状态；高度均值与量化舍入的顺序还须证明。全量logits可在结束后转换并复用累加区，不能未验证就依靠别名降低峰值。

## 4. 训练与评价契约

只允许 developmental 来源训练/调参；现有304张dev可由主控分组后约75%训练、25%调参，具体整数数量由冻结清单决定。84张val只作冻结后评价，112张heldout不打开、不推理、不用来选架构或阈值。主控可用既有身份/哈希元数据排除与val/heldout的重叠，不要求本窗口读取heldout图像。

分组单位是整牌身份及同源帧/视频，不是ROI裁剪；相同身份、源图SHA、近重复帧以及其所有候选/增强版本必须同组。清单至少包含源图SHA、ROI灰度SHA、整牌身份/标签、来源、组ID、split、四边形、采样版本、完整可见标记、教师版本和缓存哈希。多个候选每个源图的总训练权重归一为1。主控保存分组及排除理由，固定后再训练。

正样本必须是**实际自动生成且七位完整可见**的ROI，完整标签经核验；GT框可辅助核查，不能替换实际训练输入掩盖定位误差。残缺、遮挡、看不清、错误裁剪不挂完整七位标签。仅明确的背景可作为空目标；残缺含字ROI不能一概标空，也不能照抄教师猜测。首轮从CTC正样本中排除这类数据，保留独立拒识集；若阈值无法阻止其补全，下一阶段再明确增加质量头或完整性门控，不能宣布该CTC模型已满足使用要求。

教师只固定为上述Hyper模型，首轮监督损失用人工/来源真标签CTC。教师与真标签一致可辅助质量审核，不能成为唯一保留条件，否则会抹掉困难样本。若用采样权重，必须预先固定规则并报告覆盖率。教师实际ONNX输出T20、78通道，公开token表只有77项，blank=0；未映射index77明确报错/拒绝。学生T35、66类、blank=65。未定义类别映射、未知概率质量处理和时序对齐前，不做直接KL，不删除未知类后重新归一化，不任意插值CTC时间轴；soft distillation另立实验。

现有dev中290/304为“皖”。当前小实验只能验证现有域内的可训练性，不能宣称31省份泛化。扩大目标需独立来源的真实整牌，覆盖各省份、摄像头、模糊/光照、窄“1”和相邻重复字符；建议先以每省至少100个不同车牌身份作为采集规划起点，再建立身份隔离评价集，这不是充分样本量保证。字体合成仅作增强，不能充当真实省份验证；以皖为主的CCPD补量本身不解决省份覆盖。

### 受限首轮实验原定规则（已执行结果见独立报告）

1. 主控冻结分组清单、整数resize及既有后端在相同dev-tune组上的对照。先验证少量完整ROI标签、合成重复字符和一小组可过拟合样本，检查CTC实现。
2. 固定seed701、C8-native、batch16、Adam lr=0.001、weight_decay=0、CTCLoss(blank65, reduction=mean, zero_infinity=False)，梯度范数上限5。最多500优化器步或30分钟，先到即止；保存0/100/250/500步和实际最后一步的开发记录。记录loss、梯度有限性、梯度裁剪率、分支能量/epsilon命中率；NaN/Inf直接报错。一次实验不扩大通道/数据/解码搜索。
3. 只用dev-tune挑checkpoint和阈值，以同组最多3个错接收下的正确数为首要指标，同时报告分母、未过滤预测及覆盖率。若分组后的难度不同，不能直接拿原304张的175/3/126作同分母指标。
4. 冻结后评价84val，报告每图/每ROI预测、误接收、拒绝和原因、完整/残缺子集结果。训练后的dev+val合计含训练样本，不能继续包装为与原248/6/134等价的独立测试。val已被多次诊断，最终独立验收仍需另行授权heldout阶段。
5. 只有完整ROI效果在同组/同错接收约束下有实际改善，且残缺拒识门槛通过，才进入定点/QAT与RTL可行性阶段。首轮无收益时依据错误分布区分分辨率、容量、归一化、数据不足，不直接堆训练轮数。

完整性门槛：主控固定的已核验残缺集（至少包括去省份、左右截断、上下截断、空白和错误候选）不得以完整七位形式被接受；报告逐类误接收数量/分母。对已观察到0.889补全的教师样本必须明确拒绝。以此作为有限回归门槛，不外推总体误接收概率。若独立质量头必要，先量化增加的标注、参数和RAM预算再实施。

QAT阶段另行启动：固定上述W8A8/累加位宽，BN折叠，量化能量与倒数，导出int16 logits。先逐层误差和逐ROI浮点/定点配对，要求没有新NaN/溢出、没有新增已核验残缺误接收；在84val上可暂定最多损失1个正确且不新增错接收作为工程容差，由主控冻结。小样本计数不能证明低总体误接收率。未完成这些检查前不输出可用硬件权重。

## 5. CTC、置信与拒识接口

默认greedy：每个时刻66类argmax，连续相同非blank合并，blank重置前一符号，随后去blank。相同分数取较小class ID。相邻同字符必须有blank分隔；CTC可行长度要求 `T≥L+相邻重复数`，七位蓝牌最坏需要12步，T35/T18都满足。不能把T压到7还声称可识别所有重复牌号。

蓝牌七位语法在collapse后检查，不逐时刻按字符位置硬mask来强制补七位。长度非7、非法位置/字符、低置信、不完整ROI均拒绝。候选置信优先使用greedy所得完整标签的精确CTC总概率，建议score=`logP(label|ROI)/7`，阈值只用dev-tune校准。概率高不能覆盖完整性失败。

T35×C66为2,310次类别检查；七字符标签的CTC前向DP有15状态、35步，即525个状态更新，两行INT32状态120B，另需softmax/logsumexp或等价定点运算/LUT。该代价不能省略，也尚未证明现有量化精度。beam10校准后未优于greedy参考，首轮不引入beam硬件。多ROI按合法且通过完整性/阈值的最高score选整图结果，同分按固定候选序号。更换检测器与只换后端必须分别报告。

## 6. Ti60成本与进入RTL的门槛

以下来自实际运行 `lprnet_cost.py`，详细层形状和哈希见同目录 `lprnet-cost.json`。MAC仅计Conv；没有把池化、能量、倒数和CTC偷偷计作免费。

| 模型 | 参数 | Conv权重数 | Conv MAC | 最大层输出元素 | 最大物化输入+输出元素 |
|---|---:|---:|---:|---:|---:|
| 公开LPRNet68 | 446,976 | 443,344 | 144,411,264 | 230,400 | 288,000 |
| C8 24×94 | 17,960 | 17,276 | 2,028,256 | 16,192 | 23,392 |
| C16 24×94 | 36,932 | 35,828 | 5,436,064 | 32,384 | 46,784 |
| **C8 48×160** | **13,736** | **13,052** | **3,980,560** | **58,144** | **85,600** |

native参数更少是因为将最终高核改为1×1、通过空间步长减高，并非高分辨率天然省参数。完整保留四个主干tap会达146,936元素；这些峰值是不同存储策略的指标，不能机械相加，也不能只看13KB权重就判断能装下。原样物化网络不适合剩余片上空间，必须做行缓存/分块、融合和上下文重排。

首选8 MAC lanes，1输入广播、每lane每周期1 MAC；不假定每DSP打包两个INT8。原调度568,652周期，交换末端高度均值后453,362周期，100MHz理想卷积时间4.53362ms；16/32 lanes分别371,034/336,734周期。更多lane受窄通道利用率限制，不是线性加速。

8 lanes按每16bit ROM bank服务两个INT8 lane、512字/RAM10建模，按输出通道补齐后权重14,104B、16 RAM10；16/32 lanes为24/32 RAM10。312个折叠bias共1,248B，约2 RAM；若每输出通道保存32bit缩放另1,248B，约2 RAM，额外指数/控制量须再核算。未bank化原始W8+bias32是14,300B，不能拿它替代实际bank数。

现有分模块证据：视频106RAM/85DSP，显示16RAM/3DSP，frame_reader7RAM，perspective_quad2RAM/1DSP，外部224×64灰度暂按14RAM预算。合145RAM、89DSP，对204RAM/128DSP上限名义余59RAM/39DSP，尚有定位器及整合开销。旧geometry分类36RAM会被替换，不能既保留又重复扣除。分模块求和不等于整机map。

供主控评审的**分配目标而非已实现资源**：权重16 + bias/scale4 + 主干工作区12 + 上下文14 + CTC/LUT2 + resize1 + 控制1 = 50RAM；合现有预算195RAM，剩9RAM给尚未合算模块。尤其12RAM主干工作区仍缺完整调度/存活期证明；平均池化窗口缓存、端口冲突、resize与外部灰度RAM访问、能量倒数资源均可能突破该目标。开始RTL前必须拿出逐层buffer尺寸、生产消费时刻、RAM端口分配和整体峰值。若证明不了，回到模型简化或明确的外存方案，不能省略缓存后声称可装入。

时间也只能给情景：卷积有效利用率0.25/0.5/0.75时约18.13/9.07/6.04ms，再加非卷积、DMA等待与CTC。物化各Conv/Pool输入输出的参考流量为602,824B/ROI；在10/25/50MB/s下仅搬运约60.3/24.1/12.1ms。此流量未含上下文等额外操作、也未计融合可减少的访问，既不是完整总流量也不是硬下界。没有时序/带宽实测前，不承诺实时帧率。
