接口里的 64 bit、valid/ready、frame_id、epoch 是什么

普通 RGBY：每个像素 32 bit，[31:24]=Y，[23:16]=R，[15:8]=G，[7:0]=B；64 bit 一次带两个相邻像素。Sobel 把 Y 字节换成二值边缘，Canny 暂存两位分类；最终边缘在显示读回时合入。

valid && ready 表示这一拍数据被接收；sof/eol/eof 表示帧首/行尾/帧尾；frame_id 绑定原帧；epoch 绑定这一帧使用的配置。参数在帧边界和任务开始时锁存，不是中途对某个像素临时改值。

普通路径的 RGB 保留用于彩色与红边叠加。03 页 denoise=1 时，24 bit 载荷改为 {原灰度, 滤后灰度, 未滤波边缘}；最高字节继续携带主链边缘。因此它的灰度前后对比不从普通 RGB 重算。

局部处理通过 result_pixels/result_valid/result_ready 写回 DDR。local_done 后按配置执行 Canny 全帧连接，再按 recognition_enable 执行形状识别。全部成功后才发布 job_done/job_ok 对应的结果槽、框和类别。
