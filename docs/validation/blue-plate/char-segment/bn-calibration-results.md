## 严格按授权执行的一遍校准

来源为独立训练1250步冻结best.pt，SHA256 `f4689e4132485fdca7aa64633fc03d0527e1ad82ede870e897ec0ae3f5a07397`。

1. 新建独立模型加载原权重；原checkpoint不改。
2. 将两个Dropout的p临时从0.5置0。
3. 仅用原清单顺序的207个完整train ROI，batch16，12批16张+最后1批15张，调用本机官方 `torch.optim.swa_utils.update_bn` **一次**。
4. 恢复两个p=0.5，并切到eval；单独保存、冻结校准后checkpoint，随后才评价tune。

保留官方函数的重置running统计和逐batch累积平均行为；最后15张batch与其他batch等权，没有换成另一个自定义矩估计器，没有扫描batch大小或重复校准。

零优化器步骤，所有named parameters逐项完全相等。改变项恰为6层BN的running_mean、running_var、num_batches_tracked，共18个buffer；6个counter均为13。dropout已恢复，评价前后所有校准状态逐项相同；tune不参与BN更新，val/heldout图片未读。

校准产物：`tmp/blue-plate-char-segment/bn-calibration/calibrated.pt`，SHA256 `fc3c264449059987ff4017956aab98a899fa99a71791b537d9cc796f2bd02d21`。这是独立研究产物，不替换已有部署权重。

## 实际效果

| 指标 | 原checkpoint | 一遍校准后 |

| train完整正确/207 | 38 | 66 |

原门限-0.2126348189，校准后≤3错门限-0.2323796238。所有计数按相同76源身份聚合，不以78个候选ROI替代分母。

BN漂移是实际损失来源，且固定统计校准恢复了一部分性能；校准后仍有141/207训练牌未完整识别，不能把剩余问题只解释成推理统计。当前checkpoint的原配置延长、dropout对照、BN诊断与一次官方校准已经留下明确证据，继续重复校准没有依据。

## 数据覆盖研究与具体下一步

本次进一步统计了冻结标签元数据，没有读取任何新图片：207个train身份共1449个字符，只覆盖65类中的41类。34个字母数字类均出现；省份只有7类，其中皖198张、浙3、苏2、沪/粤/闽/鲁各1，其余24省份没有训练正样本。train含相邻重复的58张，tune为22张。

**未见字符只能解释一小部分tune困难。** 76个tune身份中，只有“冀F88P94”“豫NDM871”含训练未出现的字符；其余74个身份字符均已见过。加上训练集本身只66/207完整正确，现有证据不支持把总体失败归结为省份缺失，也不能承诺只加数据就能解决当前欠拟合。

本地 `images/ccpd_10k` 实际只有500个JPEG路径，全部已进入现有划分；目录名不代表另有一万张可用于训练。没有把val/heldout重分为train。

已重新核对[CCPD官方仓库](https://github.com/detectRecog/CCPD)及本地固定提交 `02aaea15137c4d2fe662e57d257c6822356e9304` 的README、LICENSE、`rpnet/load_data.py` 和tree清单。官方提供CCPD-Base训练/验证划分，困难子集用于测试；Green是八位牌，不纳入本七位蓝牌任务。读取实际loader确认标签来自文件名字段，官方定义中的O占位不等于合法字符。官方训练名单路径为 `split/train.txt`；web获取该大文本因大小上限失败，本轮未下载或假称已完成名单筛选。

建议主控下一步先准备一个**最多2048个新增、身份独立的development正样本清单**，作为后续预训练迁移/蒸馏或重新设计训练实验的数据基础，而非继续改这个checkpoint：

1. 从官方CCPD-Base训练名单取来源，记录原始文件名、来源版本和文件SHA；排除与现有全部500身份和SHA的重叠。只使用既有heldout身份/哈希元数据排重，不读取heldout图片。
2. 保持当前76tune、84val、112heldout不变；新增数据只进train。新数据间及与已有train做近重复审核，不能把精确SHA去重宣称为场景隔离。
3. 固定320检测器与Q32链路生成实际自动ROI；逐ROI核查七位可见完整，残缺、疑似错标和其他文字保留待核，不挂完整标签。交付含身份、源SHA、角点、ROI SHA、来源split和完整性复核字段的清单。
4. CCPD扩充先用于当前域内字母数字序列覆盖，不宣称解决31省份。省份泛化需单独获取缺失省份的合法真实整牌来源与身份隔离评价。

2048是下一次数据准备的规模上限，不是保证精度的样本量；本轮没有下载新增图像或开始新训练。当前固定输入教师仍是准确率参照。已有公开LPRNet权重可供离线对照，但其448个RAM10的8-lane权重bank预算本身超过器件总204个RAM，不能直接称为当前片上可部署的预训练替代品；更轻的可复用权重路线需要独立结构/权重审计。
