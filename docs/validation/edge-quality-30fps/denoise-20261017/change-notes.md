# 去噪与算法串接调整

依据用户实拍：03页M1右侧比左侧散点少，但T24仍保留大量弱纹理；06页为M0、T24。源码确认每页进入都会关闭中值，且高斯滤波在局部对比≥8时把原始中心像素混回一半。

参考实际阅读的[OpenCV官方Canny示例源码](https://github.com/opencv/opencv/blob/4.x/samples/cpp/tutorial_code/ImgTrans/CannyDetector_Demo.cpp)第25—35行：先进行3×3平滑，再做双阈值Canny。示例使用均值滤波；本工程保留现有3×3高斯窗口，采用标准权重[1,2,1;2,4,2;1,2,1]/16，删除混回细节的分支。源码通过网页读取，未下载或执行外部程序。

选择最小修改：阈值24提高两档到56；03默认中值开，仍允许K2开关；04—08固定中值开。中值9像素排序本身保留，避免新增窗口、存储和滤波器。Canny保留NMS、双阈值和滞后连接，改善前置去噪。

内部复用：DDR原始帧→中值→高斯→Sobel梯度→NMS/分类→后处理。Sobel模式旁路高斯和Canny专属阶段；03对照左侧另用中值已有的原始窗口算未去噪Sobel，右侧走主处理链。同一帧和阈值贯穿左右；04固定中值开，接的是滤波后的Y。07红边同样采用本次更新的Canny结果。

只运行本次预设和高斯计算的短检查，随后编译和加载；不运行全量回归。噪点、细线与主轮廓的实际观感交给用户上板确认。
