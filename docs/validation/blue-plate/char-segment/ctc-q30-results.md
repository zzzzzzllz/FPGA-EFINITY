## exp和阈值的向外界证明

执行前已冻结[合同](ctc-q30-plan.md)。核心实现在 `ctc_interval.py`，一次验证入口为 `verify_ctc_q30.py`，输出目录 `tmp/blue-plate-char-segment/ctc-q30/` 已有时拒绝覆盖。

logit尺度按原binary64的精确有理数表示为 `5320960402170531 / 18014398509481984`。每个d=0..1020均先精确缩放到y≤1/8，再用Fraction交错级数S31/S30夹住exp(-y)，向外取Q128整数界并逐次向外平方。所有运算的区间包含关系由有理数及整数floor/ceil保持，**没有用普通double exp生成界**。

`exp-certificates.json`保存全部1021项的d、缩放次数、精确y及最终Q128界。Decimal 220位exp对全部证书交叉检查通过；它只做复核，界的正确性来自交错级数余项与正区间平方的单调性。d=1..70的Q128界均落在同一个Q30网格单元，d≥71的完整范围均落在[0,1]/2^30内；尾部没有当作精确零。

严格门限的精确binary64有理数为 `2236422396795567 / 2251799813685248`，直接取七次方得到T，无exp/log近似。其Q30向外界为 `[1023453812,1023453813]`。因此部署时只需32bit常量 **1023453813**：

```text
L >= 1023453813  → 确定接受
U <  1023453813  → 确定拒绝
其他            → 未决
```

该整数比较与精确有理数判定在全部392项上一致。离线参考使用Fraction检查边界；硬件不需要保存数百位的阈值分子/分母。另有恰好网格阈值的等号测试，确认“接受包含等号”。

LUT仅71个uint32下界字，共284B；非零项上界为下界+1，零差上界精确为2^30。LUT SHA256为 `48f3a6a46a60475b0fcef98d4ee9a79ba42c44a7b472f59418fb6e47fa5d6743`，已在读取真实logits前冻结。

## CTC与候选排序检查

- Fraction枚举短序列全部路径，44个目标案例的精确概率均在Q30界内，包含重复字符、blank、空目标和无路径。
- 合法七字的15状态确定路径、blank-only、长于时间步的零路径均通过；上一时间步状态与当前状态分开，重复标签禁止跳两状态。
- 4项阈值检查覆盖阈值上下格点、横跨阈值及恰好等号；5项排序检查覆盖精确点同分、已证明相同输入、非同分重叠、严格分离和无候选。
- 使用真实ROI0 logits复制为索引9和2的两个候选，概率界重叠但输入/目标完全相同，可证明精确同分，正确选择索引2。不是根据相同浮点显示分数猜测同分。

## 有限位宽与存储

| 算术项 | Q30保守位宽 | 本组最大实测 |
|---|---:|---:|
| 68项exp和 | uint37 | 32bit |
| 发射概率除法分子 | uint61 | 61bit |
| 三个前驱上界和 | uint32 | 31bit |
| DP概率乘积 | uint62 | 61bit |

概率界用uint32存储；单列68个上下界544B，加15状态两行上下界240B，共784B，再加284B LUT，共1,068B。保持既定2 RAM目标，可将两个512×20银行并联为512个有效32bit字：LUT占0..70，单列概率界占71..206，DP占207..266，共267字。表读与状态访问串行复用该端口，不能假定单个RAM已有32bit口或表/DP同时访问。离线Python物化完整18列用于核对，不作为硬件存储分配。logits沿用既有银行；64bit乘除、端口控制和时序仍需实现验证。

32bit前驱和是无符号，不能直接送入signed32×Q31接口而不处理符号。上一份补充合同的17×8分段乘法应使用零扩展高半字，并保留完整uint64组合；本轮没有编写RTL。

若主控决定处理上述排序重叠，Q31仅从容量上看需要约73个表项（292B）、uint38分母、uint63除法分子、uint33前驱和及**uint64**最坏DP乘积。概率端点仍可存uint32，但33bit前驱不能套用原32bit拆分，最坏乘积也不能放signed64；例如16bit拆前驱需要三个分量，与五个7bit乘数段形成15个局部积。此处只是下一位精度的成本测算，**未生成Q31候选、未跑Q31数据，也不保证Q31解决所有未决**。

`development-roi-intervals.json`、`validation-roi-intervals.json`含每个ROI的Q30界、Q128证明参考界、原浮点概率及状态；两份 `*-frame-comparison.json`保留逐图选择和差异标记。真实帧 `unresolved.json`、`differences.json`均为空；合成未决单独保留，未混入原图计数。`finite-interface.json`给出整数阈值字、状态/表容量和位宽。

源码、LUT、输入logits、原模型与门限保持冻结；本轮图像读取0、网络推理0、训练0、112读取0。结论是固定Q30在当前冻结logits上的离线等价验证通过，通用多候选排序仍存在明确未决边界。原顺序projection预算仍为LPR纯MAC181.89792ms/ROI和新增37,184B DDR；不恢复旧高度交换预算，不宣称全网RTL、完整资源/时序或整机通过。
