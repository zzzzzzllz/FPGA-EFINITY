# geometry signed11：独立硬件验证

同一 `char_linear` 内核增加了10/11位权重参数，默认10位候选、ROM文件及门限保持不变。geometry实验只提供ROM和单核参数包装，不替换candidate，也没有并行放置两套分类核。RTL、默认回归、两档边界和映射后检查均通过，最终证据已冻结。

## 修改与导出

- `WEIGHT_BITS` 追加在原参数列表末尾，避免改变既有位置参数含义。只允许10、11，其他值time0明确报错。
- 特征保持无符号6位0..32，乘法前零扩展为signed7；权重ROM与读寄存器随位宽变化；乘积宽为 `WEIGHT_BITS+7`，按有符号规则扩展为32位。累加、输出、门限比较和分差仍为signed32。
- 320特征、65类、按位置约束、不同类别top2、较小ID同分优先及状态机不变。ROM路径已有参数，本次没有改变默认路径。
- 实验目录 `tools/blue_plate/char_model/experiments/geometry11/` 中的 `geometry11_char_linear.v` 仅实例化一次共享内核，设置11位ROM及geometry原普通门限：省份score≥174、margin≥4417；字母数字score≥−21431、margin≥4068。

源权重NPZ SHA256为 `b21a547399f17ecb50264d489eec4e4563c2269babab7149dc5447f7a12f5391`。逐值反向解码20800个binary权重和65个bias，全部等于NPZ；权重范围[-586,468]。binary文件每行恰11位，按 `class_id*320+feature_id` 排列，不能截断。

恰有一个系数超出signed10：ID55（数字0）、特征120，值−586。截断为10位会错误变成+438。本轮用该特征为32、其余为0的单项输入专门核对65个分数。

所有合法输入的保守绝对累加界为531070，signed21可容纳；分差保守界1062140，signed32有余量。本轮继续保持32位，不因模型范围缩窄输出。

研究依据为实际阅读的既有同步ROM/DSP模板与 [Efinity Synthesis User Guide](https://www.efinixinc.com/docs/efinity-synthesis-v4.4.pdf) 的参数化有符号乘法示例：乘积采用两输入宽度之和，保持同步RAM读。没有引入新依赖或重新实现分类算法。

## RTL验证

| 配置 | 向量 | 逐类分数比较 | 输入完成后周期 |
|---|---:|---:|---:|
| 原默认candidate，signed10 | 159 | 10465 | 41796 |
| geometry signed11 | 320 | 20930 | 41796 |
| 合成signed10边界ROM | 36 | 2470 | 41796 |
| 合成signed11边界ROM | 36 | 2470 | 41796 |

比较数包含额外的hold复位及重算。geometry的320组由全部259个冻结真实ROI、57组极值/固定种子随机输入、1组实际−586系数探针、3组同分总线注入组成。真实ROI保持一次normalize，未重跑切分，也未消费留出集。

两档边界ROM明确标记为合成测试夹具：10位覆盖−512/511，11位覆盖−1024/1023以及−513/512等过界值；两类分别把全部320个权重设为正最大/负最小，用全32特征检查完整累加。它们不是训练模型，也未写入实验geometry ROM。宽度9、12都被内核明确拒绝。

每组继续验证全部65个有符号分数及top2结果；同时检查输入停顿、忙碌输入噪声、输出反压、load/MAC/hold复位、非法位置和特征。测试没有放宽断言。扩充边界测试时驱动循环变量误覆盖权重位宽，被新增合法范围检查捕获；修正脚本后两档边界测试通过。

主控在隔离目录独立重算了ROM、门限、位置允许集合、全部预期分数和结果，再运行geometry320组、11位边界36组及默认159组，全部通过。审核源文件哈希与本轮一致；原始记录位于 `tmp/blue-plate-review/geometry11/review-result.json`，交付时一并归档。

## 映射后检查与交付状态

映射后检查通过：9组向量、715次逐类分数比较（包含额外两次复位相关计算），延迟均为41796拍；输入停顿、输出反压、load/MAC/hold复位及非法输入断言全部通过。覆盖5个真实ROI（含目标Y、V）、全零/全32/交替极值3组及−586探针1组。
