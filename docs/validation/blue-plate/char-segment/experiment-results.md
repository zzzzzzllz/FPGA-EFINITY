# 受限整牌学生实验结果

2026-10-18。**当前C8学生没有改善识别效果，停止此候选训练，不进入量化或RTL。** 同一76个开发调参身份组，冻结旧后端为49正确/0错误/27拒绝；学生为0/0/76，未过滤输出也没有一条完整正确号码。这是本次训练配置未达到目标，不是“13KB模型无法识别车牌”的证明。

实现及结果均在char_segment独占范围。共100步单牌拟合检查、另起随机初始化的400步开发训练，总计500步；GPU训练计时合19.65秒，不含准备/教师对照/看图审核。训练未达到30分钟上限，未额外延长。val84和heldout112的图片均未读取；没有修改旧后端、共享RTL或既有权重。

## 训练与冻结

固定C8-native、seed701、batch16、Adam 0.001、无weight decay、梯度范数上限5、dropout0.5、CTC blank65/mean/zero_infinity=False；目标不含blank，T35满足重复字符的对齐要求。每批先均匀选源图再选其完整ROI，未对重复候选加权偏置。

单牌100步：eval CTC损失63.67→1.12，目标“皖AF3188”，输出“皖8318”。数值链路可优化，但**没有完成单牌七位过拟合**。随后400步试验沿用预定配置，重新初始化，不继承单牌权重。以后进入更大训练前应把完整单牌/小组拟合作为硬门槛，不能仅以loss下降代替。

|---|---:|---:|---:|
| 0 | 60.8488 | 0/0/76 | 0% |

按预定“最多3错下正确最多，再少错、再低loss、再早step”规则冻结step400。全部候选都不满足七位格式，校准选择的score阈值1.0表示全部拒绝；没有通过提高阈值隐藏原本正确的输出。checkpoint SHA256：`48def2e7220b249d8515b1c14040447a91edd1b5a08a187cbed9c923421e88a5`，位置 `tmp/blue-plate-char-segment/experiment/pilot/step-0400.pt`。这是研究失败样本的冻结产物，不是部署权重。

## 已核验的失败原因范围

1. **训练集本身也未拟合。** 207个正ROI的greedy完整正确为0；输出长度2/3/4/5/6分别61/84/42/15/5，集中“皖A”“皖A1”。训练集eval损失2.8125，blank比例86.25%。不能把当前失败只归因于train/tune泛化差距或缺少某省份。
2. **没有数值发散/epsilon夹紧证据。** 400步全部loss与梯度有限；18.75%步骤触发梯度裁剪，分支能量最小0.02056，epsilon命中0次，权重确有更新。不能将失败解释成梯度全无或除零。
3. **BN推理统计不是单独可解决的根因。** 不更新权重，关闭dropout，仅把BN切为当前batch统计做诊断，train和tune完整正确仍为0；所有内存中的BN统计随后丢弃。未将这个诊断作为可部署模式。
4. **输入信息不是目前最强瓶颈证据。** 同一输入在固定教师上可识别；学生尚未建立完整CTC对齐。教师的容量、预训练和架构均不同，所以这一对照不能证明学生网络一定可训练成功。

当前最符合观察的是：在这套小通道骨干、动态能量缩放、dropout及从头训练配置/步数下，模型仍偏向blank和高频前缀，未形成完整序列。一次400步试验不能区分训练预算不足、优化条件不匹配和容量不足；不能直接宣布其中某项已是根因。

已重新核对[PyTorch CTCLoss接口](https://docs.pytorch.org/docs/stable/generated/torch.nn.CTCLoss.html)及[固定公开训练实现](https://github.com/sirius-ai/LPRNet_Pytorch/blob/7c976664b3f3879efabeaff59c7a117e49d5f29e/train_LPRNet.py)。本实现的维序/log_softmax/blank和长度符合接口；公开复现实际用RMSprop(alpha0.9)，并非本契约的Adam。论文训练规模也远超本受限试验。这是后续要隔离验证的条件差异，不是更换优化器必然成功的依据。

## 拒识与后续方向

冻结模型对16个完整tune ROI分别生成左20%、右20%、上25%、下25%裁切及空白，共80个探针，全部拒绝；主控明确指出的 `left20_removed-0001-0002.png` 也拒绝。因为完整牌同样全部拒绝，这不能计作实用拒识能力通过。没有训练独立质量头，也没有把残缺牌挂完整标签。

建议主控先决定下一次**小组拟合门槛实验**，不继续当前400步checkpoint的大范围训练：先在同一小组完整ROI上取得七位精确拟合，再逐项评估降低dropout或将输入相关能量改为固定缩放的简化学生。后者同时减少定点倒数代价，但需从头验证，不能直接替换当前checkpoint推理公式。若简化后仍无法拟合，再比较较宽通道；若能拟合但独立组不改善，再补充真实多省份development数据。每次只改一个有证据的因素，另行冻结预算与判断标准。

目前无需主控补传ROI清单：320角点、源SHA和标签元数据均已取得。若下一阶段要求人工复标而非本窗口看图，待核名单就是 `visual-review.json` 的30项，须人工确认完整性和转录后才能增加训练正样本；不要把现有Codex复核记录写成人工签字。
