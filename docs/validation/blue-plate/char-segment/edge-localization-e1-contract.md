# E1：冻结粗候选后的实际文字行精修

E1只复用E0 A的417个候选记录。44个原边界拒绝候选继续记录并跳过，373个有效候选各执行一次固定局部流程；最多读取既有304个development源图一次。全帧定位、全帧Otsu、OCR、训练及84/112读取均为0。源图重新生成canvas后必须与E0画布SHA一致。

## 源码依据和适配

已复读并联网核对 [EasyPR plate_locate.cpp](https://github.com/liuruoze/EasyPR/blob/a0a9f3c3f612e7c8d9046bd9c5770249cfb86850/src/core/plate_locate.cpp) 的局部二次搜索，及 [OpenALPR characteranalysis.cpp](https://github.com/openalpr/openalpr/blob/master/src/openalpr/textdetection/characteranalysis.cpp)、`linefinder.cpp/getBestLine` 的实际组件尺寸过滤、组件对提线和文字区域提取。读取本地已有源码，不重复下载。只借鉴机制，不复制AGPL产品代码。

采用实际组件提出文字行，避免先拉伸粗框后用固定字符位置猜几何。OpenALPR的0.97/1.03行容差乘绝对y坐标，平移后会改变，这里改为相对字符高度；不使用其最长线作为完整性证据。不采用EasyPR人工连接横线、颜色裁边或从第二字推算首字。此版本也不遍历OpenALPR的多阈值、多尺寸设置。

## 固定局部规则

1. 在E0扩展粗框原尺寸中，用既有整数灰度 `(77R+150G+29B)>>8`。正、反灰度各执行一次原32-bin Otsu。单灰度失败单列；不做额外形态连接，不改变颜色输入。
2. 8连通组件沿用已验证RLE：128行游程、256活动标签，最多保留256个高度至少3像素的组件。已结束的其他组件只进诊断日志，不占持久候选表。面积≥3、高≤粗框0.8倍、宽≤粗框高度0.9倍的碎片最多64个；超限拒绝，不保留前K。组件触碰搜索边界的身份单独记录。
3. 提线锚组件高≥6且占粗框高至少0.20；宽高比0.06…0.90，填充率0.05…0.90。最多64个锚，因此最多2016个组件对。配对高度最小/最大≥0.65、中心斜率绝对值≤7/80。
4. 组件对的平均高度记H。选择高度0.15H…1.30H、面积≥0.02H²、中心距提议线≤0.35H的实际碎片。按左x、上y、组件身份排序；相邻碎片水平间隙≤0.10H且合并总宽≤0.85H才合并。没有像素就不建立组，首字也使用相同规则。
5. 字组高0.65H…1.30H、宽0.06H…0.90H、填充率0.08…0.90。检查按x排序的连续七组：高度比≥0.65、不得水平重叠，相邻中心间距为中位间距0.45…1.80倍。允许实际碎片合并成中文首字；不预留空的“首字区”，不把两组之间的空白补成字符。
6. 对七组中心做有理数最小二乘行拟合。斜率≤7/80、最大中心残差≤0.30倍最大字高。实际七组包围范围左右各加其跨度1/20，上下各加中位字高1/4，形成沿文字行的四边形。几何使用精确有理数，再按ties-to-even取Q16；阈值比较均为整数交叉乘积，没有绝对坐标容差。
7. 七组任何一组触碰粗框搜索边界即拒绝；最终四角也必须留在该搜索区域内且有1像素余量。不靠外推到未观察区域宣布文字完整。候选首末组及全部成员身份保存，但仍不能代替人工无遮挡标注。
8. 同一极性按七组实际组件身份去重，最多16个几何假设；两极性分别记录。每个几何从原彩色画布按既有Q32/Q5采样224×64，然后运行原七区结构和行一致性检查。正反极性共同产生的完全相同Q16四角只计一项，其他框不做GT相关合并或OCR排序。
9. 全帧遍历417候选在本帧对应的全部条目后，最多保留32个不同四角的精修几何。任一局部容量溢出或帧几何超32均使整帧失效。恰好一项通过原结构才选中；0项拒绝，多项ambiguity拒绝。确定性排序是Q16四角字典序，不以排序首项掩盖歧义。

所有比例为本实验适配值，未观察E1开发图结果前冻结，不称为上游原参数。流式容量模拟不等于现有RTL已经实现局部组件对搜索或满足吞吐。

## 诊断与验证

对373个有效原粗框另外复现E0原采样与结构，用AST只在原函数return位置记录退出原因；每条旧mask SHA、rects及通过状态必须完全一致。补充分辨全局单灰度、谷值>8、空区、字高不足、字宽>36及局部Otsu单灰度。该复现是诊断，不是第二次E1精修或新全帧定位。

局部算法与唯一选择完成后才接入GT评价。报告全304、旧正确251、预声明几何域303及E0上游缺失64帧；后者身份固定为E0所有候选既不完整包含GT又无IoU≥0.5的集合。分别记录新增/丢失定位、误框、IoU0.5/0.7、GT四角包含与前景裁失诊断。保留全部失败；局部有效域改善不能当作整体替代达标。

测试先用合成字组检查：中文首位两个实际碎片合并、缺失首位不补字、平移不改变规则、触边拒绝、65碎片溢出，以及结构诊断与冻结函数一致。原尺寸粗框BGR和最终BGR裁剪保存为压缩缓存，用于后续检查而不再读源图。

代码：`edge_local_refine.py`、`run_edge_local_e1.py`。`prepare`冻结身份、合同和源码SHA；`run`只执行一次，禁止覆盖；产物在 `tmp/blue-plate-char-segment/edge-localization-e1/`。本实验不改变E0、产品RTL、OCR输入参数、模型或README。
