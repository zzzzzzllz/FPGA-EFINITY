# 任务 8：圆形、矩形识别调参

加载配套程序后，运行 `coding/edge-quality-30fps/recognition.cmd` 进入任务 8；也可以按 KEY1 翻到 `08 SHAPES`。该入口不重新下载程序，不改摄像头曝光/增益。任务 8 自动开启识别。

| 操作 | 效果 |
|---|---|
| KEY2 短按 | 阈值 T 降低 4，保留更多弱轮廓 |
| KEY3 短按 | 阈值 T 提高 4，减少弱噪点 |
| 持续按住 KEY2 / KEY3 | 约半秒后连续调整 |
| KEY1 短按 / 长按 | 下一页 / 上一页；回到任务 8 保留调整值 |

屏幕菜单显示 `K2 T -4 / K3 T +4`，底部 `T=` 是当前显示帧实际使用的阈值。首次进入从 56 开始，范围 1—2040；重新下载或复位后回到 56。按键不会关闭识别。

固定目标后，轮廓断裂先按 KEY2 降几个档；背景碎线过多则按 KEY3 提高。调节的是边缘检测阈值，不是原图的灰度亮度。低阈值默认随高阈值保持 1/2，连通处理保留与强边缘相连的弱边缘。

识别前使用中值和 3×3 均值平滑，减少噪声引起的轮廓闪动；没有冻结画面或叠加历史帧。显示底图仍保留原彩色像素，红线是实际送入识别的边缘。绿色框及 CIRCLE / RECT 是识别结果，只有红线不表示识别成功。

每帧形状计算设有约40ms预算；超出时等当前内存请求完成，清空本帧识别框，继续显示边缘。识别数量旁的 `+` 表示过载或目标数量超出上限；此时可提高 T 减少背景碎线。它不表示已经识别成功。

识别尺寸限制仍为圆直径或矩形短边 64—400 像素，目标离画面边缘至少 16 像素。先让一个完整目标占据画面中央，避免轮廓和背景线连接。
